#{* 洛杉矶 · 全局变量归一化 必须是每个页面的第一个 include（排在 Boot.html 之前）。 为什么需要它：核心并不是每页都下发 $user —— CLOSED 与认证四页 控制器根本没传，会员页也只在登录时才 assign。Smarty 对未定义变量的 裸访问会抛两条 PHP Warning（Undefined array key / Attempt to read property "value" on null）；display_errors 打开时它们会直接印到 HTML 里。 只有 |default: 与 isset() 两种写法是安全的，所以在这里一次性把 可选变量补齐成 null，后面所有模板就能放心裸用。 *} #{assign var=user value=$user|default:null scope="global"} #{assign var=group value=$group|default:null scope="global"} #{assign var=setting value=$setting|default:[] scope="global"} #{assign var=langs value=$langs|default:[] scope="global"} #{assign var=config value=$config|default:[] scope="global"} #{assign var=isBusinessSite value=$isBusinessSite|default:false scope="global"} #{assign var=from value=$from|default:0 scope="global"}
