## 使用前提

支付接口需要依赖支付插件：`微信支付-接口(个人挂机版)`，请去应用商店安装此支付插件，此插件可免费安装

## 基本配置

- API URL：你的支付回调域名，需要加`https://`或`http://`
- TOKEN：签名验证用的，需要32位字母+数字的组合，插件一般默认会帮你随机生成一个

## 支付配置

- 手机号：通过手机号转账功能
- 真实姓名：如果使用`手机号码转账`收款功能，则需要填写微信实名的姓名，因为大额转账时需要验证真实姓名
- 收款二维码：支持：`个人收款码`、`小薇商家收款码`、`经营收款码`
- 赞赏码：微信赞赏码

> 手机APP仅支持`赞赏码`，和`二维码`

## 监控使用说明

手机APP端和电脑端操作基本一致，但值得注意的是，必须停用小程序或公众号：`微信支付`、`收款小助手`，然后把微信的`服务通知`中的
`消息通知提醒`打开即可。

## 监控原理

- 就是监控通知栏消息，当你的微信收款消息无法出现在通知栏，请自行网上找教程，各家手机设置不统一

## 2.0：收款账号改在支付插件里配，支持多台手机

收款信息（Token / 收款码 / 手机号）已经从本插件搬到了
**「支付插件 → 微信支付-接口(个人挂机版) → 配置」**，一套配置 = 一个微信收款账号 = 一台挂机手机。

- 想用第二个微信号收款：新建第二套配置，把它的 Token 填进第二台手机，再新增一条支付接口绑定这套配置即可。
- 每套配置的表单顶部会直接列出该台手机要填的 **API URL** 与 **TOKEN**，照抄即可。
- 不同配置之间收款金额互相独立：两台设备可以同时挂着同一个金额的订单，各收各的，不会互相顶掉。

**挂机端 App 完全不用升级**：上报地址、参数、签名算法、返回值都和 1.x 一模一样。
服务端会用各套配置的 Token 逐个验签，签得通的那套就是这次上报的来源设备，然后只在该设备的订单里核销。

**从 1.x 升级**：插件启用时会自动把原来的 Token 与收款码搬进「默认配置」，
老手机上的 Token 不用改；升级前建的订单也仍能正常核销。本插件页面现在只剩一个「订单有效期」。

## 收款码上传后提示"无法识别"

二维码解析对图片尺寸很敏感：手机截屏那种一两千像素宽的收款码分享图，整张丢给解码器反而读不出来。
插件会自动把图缩到几个经验尺寸依次重试（必要时再做灰度增强），绝大多数分享图都能认出来。

如果仍然提示无法识别，两条路任选：

1. **换一张更干净的图**：裁掉标题、背景、店铺名，只留二维码本身；
2. **直接填链接**：在支付插件的配置里填「收款链接（可选）」——
   微信收款码扫出来的那串地址（wxp://f2f0…）。
   填了它就以它为准，不再解析图片。

解析成功的结果会写回该套配置，之后不再重复解析。
